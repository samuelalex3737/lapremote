### Manual checks for Sam (on real phone + laptop)
1. Rebuild (`uv run --project agent python scripts/build_web.py`), restart the agent, open the app on the phone -> a dark app with a bottom tab bar, and the status pill "Connected to <laptop> · NNms".

5. With iOS "Reduce Motion" on -> tab changes don't slide.
6. Turn the phone sideways on Trackpad -> the trackpad fills the screen with the click buttons on the right.

### Known issues / deviations / protocol change proposals
- No protocol changes.
- The service worker (offline shell) only registers on HTTPS or localhost. Over plain `http://<lan-ip>` the browser skips it, and Android Chrome won't offer "Install app" (iOS Add to Home Screen works). HTTPS arrives in Phase 8.
- Launch, Scenes, Timer, Power and AI show "isn't available" with the agent's own reason until Phases 7 and 8 enable them. This is driven by `auth.ok.features`, not hard-coded text.
- Now Playing is the Phase 4 layout. The artwork glow, gradient, scrubber, swipe-to-skip and adaptive modes come in Phase 5.
- Vite warns that the main JS chunk is over 500 kB (React, motion, zod, lucide). It loads in 0.9 s on Lighthouse mobile. Code-splitting is a Phase 10 performance item.
- `npm audit`: 0 vulnerabilities in production dependencies, 4 moderate ones in dev-only tooling (Lighthouse's dependency tree). They never ship to the phone.
- Swipe navigation is tested on Chromium (CDP touch). WebKit has no touch driver in Playwright, so iOS swiping is in the manual checks.
